# 🎮 GameStoB — Gaming Marketplace Website

GameStoB is a **modern gaming marketplace website** designed for discovering, browsing, and purchasing digital games.

The project focuses on creating an engaging gaming experience through a **futuristic dark-themed interface**, responsive layout, interactive elements, and a visually appealing game catalog.

🔗 **GitHub Repository:**
https://github.com/danielgracemiracle-ops/GameStob-app

---

## 📌 Project Overview

GameStoB was developed as a web-based gaming marketplace concept where users can explore different games, view product information, and interact with a purchase-oriented interface.

The project focuses on combining **modern web development with UI/UX design principles** to create a visually engaging gaming platform.

The website includes:

* Game discovery
* Game product catalog
* Game details
* Game pricing
* Purchase interface
* Responsive navigation
* About Us section
* Location section
* Interactive UI elements

---

## 🎯 Objectives

The main objectives of GameStoB are:

1. Create a modern website for discovering digital games.
2. Design an engaging gaming marketplace interface.
3. Implement responsive web layouts.
4. Provide an intuitive game browsing experience.
5. Apply UI/UX principles to a real-world web project.
6. Implement interactive elements using JavaScript.

## ✨ Features

### 🏠 Home

The landing page introduces the GameStoB platform and provides users with quick access to the main sections of the website.

### 🎮 Game Catalog

Users can browse available games through visually designed game cards containing information such as:

* Game cover
* Game title
* Genre
* Price

### 🛒 Purchase Interface

The website provides a purchase-oriented interface for selected digital games.

### 📍 Location

A dedicated location section provides information about the platform/company location.

### ℹ️ About Us

Provides information about GameStoB and its concept.

### ✨ Interactive UI

JavaScript is used to create interactive elements throughout the website.

### 📱 Responsive Design

The interface is designed to adapt to different screen sizes and devices.

## 🎨 UI/UX Design

GameStoB uses a **dark and futuristic gaming visual style**.

The design incorporates:

* Dark background
* Neon-gradient visual elements
* Glowing effects
* Particle effects
* Hover animations
* Game-focused visual hierarchy
* Responsive layouts

The interface was initially designed using **Figma** before being implemented into the website.

## 💻 Development Process

The development process consisted of several stages:

### 1. UI/UX Design

The initial interface and user experience were designed using Figma.

### 2. Website Structure

HTML was used to create the structure of the website and organize its different sections.

### 3. Visual Design

CSS was implemented to create the dark futuristic gaming aesthetic, including gradients, glowing effects, animations, and responsive layouts.

### 4. Interactivity

JavaScript was used to implement interactive elements and improve the overall user experience.

### 5. Responsive Implementation

The interface was optimized to work across different screen sizes.
